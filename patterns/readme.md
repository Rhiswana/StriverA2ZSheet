# What is a Pattern?

In programming, a **pattern** is a particular arrangement of characters, numbers, or symbols that we generate using code.

## How to Solve a Pattern?

When solving a pattern, ask yourself:

1. How many **rows** do I need?
2. How many **columns** are there in each row?
3. What changes from one row to another?
4. What stays the same?
5. When should I print a **space**?
6. When should I print a **character or number**?
7. How many times should each loop execute?

## Pattern-Solving Approach

Whenever you see a pattern, follow this approach:

**Observe the Pattern**
↓
**Count the Rows**
↓
**Observe Each Row**
↓
**Find What Changes**
↓
**Find What Stays the Same**
↓
**Identify Spaces**
↓
**Identify Symbols / Characters**
↓
**Decide Loop Conditions**
↓
**Write the Code**
↓
**Check the Output**
