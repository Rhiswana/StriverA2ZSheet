1. What is a Pattern?

In programming, a pattern is a particular arrangement of characters, numbers, or symbols that we generate using code.



How to solve pattern ?

How many rows do I need?
How many columns are there in each row?
What changes from one row to another?
What stays the same?
When should I print a space?
When should I print a character?
How many times should a loop execute?





Pattern-Solving Approach

So, whenever you see a pattern, follow this approach:

Observe the Pattern
       ↓
Count the Rows
       ↓
Observe Each Row
       ↓
Find What Changes
       ↓
Find What Stays the Same
       ↓
Identify Spaces
       ↓
Identify Symbols / Characters
       ↓
Decide Loop Conditions
       ↓
Write the Code
       ↓
Check the Output
